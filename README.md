# number-game

##制作作品　No.1
C言語で作成した数あてゲームです。
ランダムに生成された数字を予想し、正解を目指します。
##使用技術
 ‐ C言語
 ‐ Visual Studio Code
##機能
- 難易度選択
- ランダムな数字の生成
- 数字の入力
- 正解・不正解の判定
##工夫した点
- 難易度によって出題される数字の範囲のを変更しました。
- 乱数を利用して毎回異なる数字が生成されるようにしました。
- ゲーム終了後にもう一度遊べるようにし、繰り返しプレイできるようにしました。
##学んだこと
条件分岐、繰り返し処理、乱数生成を実践的に学べました。

条件分岐を使用して、難易度ごとに処理を分けたり、繰り返し処理を使用してゲームを何度もプレイできるようにすることで、それぞれの処理が実際のプログラムの中でどのように使われるのかを理解できました。

また、乱数を使用して毎回異なる数字を生成できることを学びました。
